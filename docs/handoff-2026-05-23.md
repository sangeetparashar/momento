## 5. Bugs, Failures & Lessons Learned

**Highest-value section. Prevents the next agent from repeating these.**

- **TestFlight invite link clicked on Android = "This invitation has been revoked or is invalid"** — misleading error. The link is iOS-only and Apple's web page doesn't degrade gracefully on non-iOS devices. **Always tell testers to open the link on iPhone.** User initially thought their invite was broken; was just opened in Android Chrome.

- **Modal `position: fixed` breaks inside transformed parent** — CSS gotcha most engineers learn the hard way. Hero Join Beta CTA modal worked from navbar but not from hero. Cause: `.anim-hero` div has `translateY` transform set by anime.js (even at end of animation, transform stays applied). `position: fixed` descendants get anchored to the transformed ancestor, not viewport. **Fix: always render modals via React portal.** Pattern now in `apps/landing/components/Modal.tsx` using `createPortal(node, document.body)`.

- **Apple "Submit for Review" button is hidden until 4 prereqs done** — wasted ~10 min looking for the button:
  1. App Privacy questionnaire **Published** (not just saved)
  2. App Information complete (Categories, Age Rating, Content Rights)
  3. TestFlight Test Information saved with Privacy Policy URL filled
  4. Build attached to an External Testing group
  Once all 4 done, the button appears in three places: (a) yellow status on build row in external group, (b) build detail page, (c) modal that pops when adding a new external tester.

- **Vercel cold starts are huge (700ms) and silent** — diagnosed via 3 consecutive curl calls (`811ms / 100ms / 99ms`). The DB and code are fast; the platform spin-down is the culprit. Easy fix: add cron in `vercel.json` to hit `/api/feed` every 5min. Free.

- **Supabase Storage default `Cache-Control: no-cache`** — every media view re-downloads. Discovered via `curl -I` on a video URL: `cache-control: no-cache, content-length: 19572196` (20MB). For UUID-named files that never change, want `max-age=31536000, immutable`. Fix in SQL on `storage.objects.metadata` + bucket default in dashboard. **Easily the biggest perceived speedup available.**

- **`/api/creators/apply` is user-self-service only, no admin override** — assumed there was an admin endpoint and almost confidently called it. There isn't. Promotion flow is either (a) user applies → SKIP_KYC auto-approves OR (b) user applies → Veriff webhook approves. **No admin path. Building one is backlog #010.**

- **CSS opacity != removing element from stacking** — bumping modal backdrop from `bg-black/60` to `bg-black/92` STILL left page visible. Even 92% opacity isn't enough for demo visibility. **For modals, use solid `bg-black` + heavy `backdrop-blur-3xl`, plus high z-index (`z-[200]`).**

- **`AppShowcaseFlow.tsx` wheel/touchmove listeners on `window` capture events from inside modals** — even with modal scroll-lock via `body.overflow=hidden`, the showcase still called `preventDefault()` which blocked modal's own scroll. Fix: bail in those handlers when modal is open. Check `document.body.style.overflow === 'hidden'` OR `document.body.dataset.modalOpen === 'true'` at top of handler.

- **iOS QuickTime video uploads ~20MB for short clips** — uncompressed. Mobile app compresses images (resize + JPEG quality 0.8) but NOT video. Backlog #008 (video compression) would solve the perceived "uploads fail" UX and reduce the need to raise the 50MB cap.

- **Privy 2FA is needed for first `eas build` of prod, but EAS caches session afterward** — first build needs Apple ID 2FA code from `brian@mylz.run`'s trusted device. After that, EAS auto-renews. Same for first `eas submit` (after which it generates an ASC API Key that's permanent).

- **Apple Team Agent name shows as inviter in all TestFlight emails** — invites read "Brian Yang has invited you" even when Sangeet adds the tester. This is a team-level Apple setting, not per-invite. **Don't tell testers "I just invited you" — let them know the email will come from Brian Yang.**

- **`eas-cli credentials` for APNs is interactive-only, no `--non-interactive` flag** — needs real TTY. Walked user through the menu path manually. If automating, you'd need to use the EAS dashboard or a programmatic alternative.

- **The Supabase free tier file cap is project-wide, not bucket-wide** — even with bucket-level `file_size_limit` set to 200MB, Supabase enforces 50MB on Free. To exceed, upgrade to Pro ($25/mo). Same applies to DB auto-pause (Pro removes it).

- **`document.body.style.overflow = 'hidden'` cleanup runs on Modal unmount but the inline style might be reset by other code** — added belt-and-suspenders `body.dataset.modalOpen = 'true'` as a more explicit signal that survives.


```bash

  "$UPSTASH_REDIS_REST_URL/del/user:<id>/creator:<id>" \
  -H "Authorization: Bearer $UPSTASH_REDIS_REST_TOKEN"
```
